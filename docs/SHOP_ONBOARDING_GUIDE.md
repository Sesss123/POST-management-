# Shop Onboarding & Setup Guide

This guide covers the process of setting up a new restaurant on the RestoLedger POS SaaS platform.

## 1. Super Admin Provisioning
1. Log in to the Super Admin Dashboard.
2. Go to **Shops** -> **Create New Shop**.
3. Enter Shop Name, Identifier (Slug), and Owner Email.
4. The system will automatically:
    - Create the shop record.
    - Provision a default 'admin' user for the shop owner.
    - Initialize default settings and categories.

## 2. Initial Configuration (Shop Admin)
The shop owner must log in and complete these steps:
1. **General Settings**: Set Currency (LKR), Tax Rate (VAT/NBT), and Service Charge.
2. **Branding**: Upload restaurant logo and set receipt footer message.
3. **Table Setup**: Define floor plan and table numbers.
4. **Categories**: Create main categories (Food, Beverages) and sub-categories.

## 3. Menu Building
1. Add items to the inventory.
2. Enable **Track Stock** for items with limited availability.
3. Configure **Public Menu** settings for items that should appear on the QR menu.
4. Create **Combo Meals** for promotional bundles.

## 4. User Roles
1. Create **Cashier** accounts for billing staff.
2. Create **Waiter** accounts for table ordering.
3. Create **Kitchen** accounts for KDS access.
4. (Optional) Set up specific permissions if default roles are not sufficient.

## 5. Subscription Activation
1. Assign a subscription plan (Basic, Pro, Enterprise) via Super Admin.
2. Mark the initial payment as paid to unlock all POS features.
